# Toonwide Phase 1: Database, Minute Packs and Website Login: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A user can sign up on the Toonwide website with email + password, verify their email (which grants the
free 60-minute pack), log in, and see their minutes left on a dashboard.

**Architecture:** The existing `room-server/` (Express + Socket.IO) becomes the single backend. It is refactored into
a `createServer()` factory so it can be tested in-process, gets a Postgres database through Drizzle ORM (PGlite
in-memory for tests and local dev, node-postgres in production), auth routes under `/api/auth`, an account route
under `/api/account`, and serves the new React website built from `web/`.

**Tech Stack:** Node 20 (ESM), Express 5, Socket.IO 4, Drizzle ORM + drizzle-kit, PGlite, pg, @node-rs/argon2,
zod, cookie-parser, node:test; website: React 19, Vite, TypeScript, react-router, Vitest + Testing Library,
Playwright.

**Spec:** `docs/superpowers/specs/2026-10-05-toonwide-accounts-sessions-design.md` (sections 2, 3, 4, 5.1, 10, 11, 12)

## Global Constraints

- Product name in all new user-facing text: **Toonwide**.
- Passwords: argon2id, minimum 10 characters, rejected if in the common-password list.
- Login cookie `tw_session`: `httpOnly`, `Secure` (when the public URL is https), `SameSite=Lax`, 30 days.
- CSRF: double-submit cookie `tw_csrf` + header `X-CSRF-Token` on every state-changing website request.
- Verification links valid 24 h, reset links 1 h, single-use, only SHA-256 hashes stored.
- Login rate limit: 5 failures per 15 minutes per email, 50 per IP (shared networks), then `429`.
- Sign-up / forgot / resend emails: 30 requests per 15 minutes per IP.
- Free pack: plan `free` = 60 minutes, valid 7 days, session max 60, history 90 days; granted once, on email verification.
- No message text, tokens or passwords in logs (the `console` mail driver is development-only).
- Node 20: `node --test` with no arguments discovers `test/**/*.js` and `**/*.test.js`; keep test helpers in
  `room-server/testing/`, never in `test/`.

## Not in this phase

Sessions, launch codes, the desktop app, AI proxy, chat history, rooms auth (Plans 2–6). The dashboard's
"Start session" button is shown disabled.

```js
/** Minimal browser stand-in: keeps cookies and sends the CSRF header like the website does. */
export function client(url) {
  const jar = new Map()
  async function request(method, path, body) {
    const headers = { 'Content-Type': 'application/json' }
    if (jar.size) headers.Cookie = [...jar].map(([k, v]) => `${k}=${v}`).join('; ')
    if (jar.has('tw_csrf')) headers['X-CSRF-Token'] = jar.get('tw_csrf')
    const res = await fetch(url + path, { method, headers, body: body === undefined ? undefined : JSON.stringify(body) })
    for (const cookie of res.headers.getSetCookie()) {
      const [pair, ...attrs] = cookie.split(';')
      const i = pair.indexOf('=')
      const name = pair.slice(0, i).trim()
      const value = pair.slice(i + 1)
      const expired = attrs.some((a) => /expires=thu, 01 jan 1970/i.test(a.trim()))
      if (expired || value === '') jar.delete(name)
      else jar.set(name, value)
    }
    const data = await res.json().catch(() => null)
    return { status: res.status, data }
  }
  return { jar, get: (path) => request('GET', path), post: (path, body = {}) => request('POST', path, body) }
}
```

```js
/** Constant-time string comparison (false for different lengths). */
export function safeEqual(a, b) {
  const x = Buffer.from(String(a ?? ''))
  const y = Buffer.from(String(b ?? ''))
  return x.length === y.length && timingSafeEqual(x, y)
```

```js
import { createServer as createHttpServer } from 'node:http'
import { createRequire } from 'node:module'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'
import express from 'express'
import { Server } from 'socket.io'
import { createApi } from './api.js'
import { attachRooms, MAX_IMAGE } from './rooms.js'
import { safeEqual } from './util.js'

const require = createRequire(import.meta.url)
// Markdown rendering on the phone page: browser builds of marked and DOMPurify, served locally (no CDN).
const VENDOR = {
  'marked.js': join(dirname(require.resolve('marked')), 'marked.umd.js'),
  'purify.js': join(dirname(require.resolve('dompurify')), 'purify.min.js')
}
const ROOM_PAGE = fileURLToPath(new URL('./public/room.html', import.meta.url))

/**
 * Build the whole backend without listening, so tests can run it on a random port.
 * `config`: { appKey, publicUrl, webUrl, trustProxy, secureCookies, webDist }.
 */
export function createServer({ config, db = null, mailer = null, now = () => new Date() }) {
  const app = express()
  const http = createHttpServer(app)
  // Room for one host picture per packet; guests are still limited by the room's text checks.
  const io = new Server(http, { maxHttpBufferSize: MAX_IMAGE + 64 * 1024 })
  const rooms = attachRooms(io, { appKey: config.appKey, publicUrl: config.publicUrl })

  app.disable('x-powered-by')
  // Behind a hosting proxy (Render, Railway, nginx) this makes req.ip the real client IP for rate limiting.
  if (config.trustProxy) app.set('trust proxy', 1)

  app.get('/health', (_req, res) => res.json({ ok: true, rooms: rooms.count() }))
  app.use('/api', createApi({ appKey: config.appKey, safeEqual }))
  app.get('/vendor/:file', (req, res) => {
    const file = VENDOR[req.params.file]
    if (!file) return res.sendStatus(404)
    res.set('Cache-Control', 'public, max-age=86400').sendFile(file)
  })
  app.get('/r/:id', (req, res) => {
    if (!rooms.has(req.params.id)) return res.status(404).send('This room does not exist or has been closed.')
    res.sendFile(ROOM_PAGE)
  })

  async function close() {
    rooms.stop()
    await new Promise((resolve) => io.close(() => resolve()))
  }

  return { app, http, io, close }
}
```

```js
import { sql } from 'drizzle-orm'
import { boolean, index, integer, jsonb, pgTable, primaryKey, text, timestamp, uniqueIndex, uuid } from 'drizzle-orm/pg-core'

const ts = (name) => timestamp(name, { withTimezone: true })

export const users = pgTable(
  'users',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    email: text('email').notNull(),
    passwordHash: text('password_hash').notNull(),
    emailVerifiedAt: ts('email_verified_at'),
    createdAt: ts('created_at').notNull().defaultNow(),
    deletedAt: ts('deleted_at')
  },
  (t) => [uniqueIndex('users_email_key').on(t.email)]
)

/** Website login sessions; the cookie holds the token, the table only its SHA-256 hash. */
export const webSessions = pgTable(
  'web_sessions',
  {
    tokenHash: text('token_hash').primaryKey(),
    userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
    expiresAt: ts('expires_at').notNull(),
    createdAt: ts('created_at').notNull().defaultNow(),
    userAgent: text('user_agent')
  },
  (t) => [index('web_sessions_user_idx').on(t.userId)]
)

/** Single-use links sent by email (verify address, reset password). */
export const emailTokens = pgTable(
  'email_tokens',
  {
    tokenHash: text('token_hash').primaryKey(),
    userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
    purpose: text('purpose', { enum: ['verify', 'reset'] }).notNull(),
    expiresAt: ts('expires_at').notNull(),
    usedAt: ts('used_at'),
    createdAt: ts('created_at').notNull().defaultNow()
  },
  (t) => [index('email_tokens_user_idx').on(t.userId)]
)

/** Catalog of minute packs: "N minutes valid for M days". One-time, never recurring. */
export const plans = pgTable('plans', {
  id: text('id').primaryKey(),
  name: text('name').notNull(),
  minutes: integer('minutes').notNull(),
  validDays: integer('valid_days').notNull(),
  sessionMaxMinutes: integer('session_max_minutes').notNull(),
  historyDays: integer('history_days').notNull(),
  features: jsonb('features').notNull().default({}),
  priceCents: integer('price_cents'),
  stripePriceId: text('stripe_price_id')
})

/** Packs a user holds. Minutes are spent from the pack that expires soonest. */
export const grants = pgTable(
  'grants',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
    planId: text('plan_id').notNull().references(() => plans.id),
    minutesTotal: integer('minutes_total').notNull(),
    startsAt: ts('starts_at').notNull(),
    endsAt: ts('ends_at').notNull(),
    source: text('source', { enum: ['free', 'purchase', 'admin'] }).notNull(),
    createdAt: ts('created_at').notNull().defaultNow()

export const sessions = pgTable(

    id: uuid('id').primaryKey().defaultRandom(),

    status: text('status', { enum: ['pending', 'active', 'ended'] }).notNull(),

    endsAt: ts('ends_at').notNull(),
    endedAt: ts('ended_at'),
```

- [ ] **Step 6: Write `createDb` and `seed`**

Create `room-server/db/index.js`:

```js
import { fileURLToPath } from 'node:url'
import * as schema from './schema.js'

const migrationsFolder = fileURLToPath(new URL('./migrations', import.meta.url))

/** The pack every verified user gets once. Edit here (or in the table) to change the free offer. */
const FREE_PLAN = {
  id: 'free',
  name: 'Free',
  minutes: 60,
  validDays: 7,
  sessionMaxMinutes: 60,
  historyDays: 90,
  features: { rooms: true, screenshots: true, models: {}, limits: { answersPerMinute: 30, answersPerSession: 300 } }
}

export async function seed(db) {
  await db.insert(schema.plans).values(FREE_PLAN).onConflictDoNothing()
}

/**
 * Open the database and bring it up to date.
 * 'memory' = throwaway PGlite (tests), 'pglite:<dir>' = PGlite on disk (local dev), anything else = Postgres URL.
 */
export async function createDb(databaseUrl) {
  let db
  if (databaseUrl === 'memory' || databaseUrl.startsWith('pglite:')) {
    const { PGlite } = await import('@electric-sql/pglite')
    const { drizzle } = await import('drizzle-orm/pglite')
    const { migrate } = await import('drizzle-orm/pglite/migrator')
    db = drizzle(new PGlite(databaseUrl === 'memory' ? undefined : databaseUrl.slice('pglite:'.length)), { schema })
    await migrate(db, { migrationsFolder })
  } else {
    const { default: pg } = await import('pg')
    const { drizzle } = await import('drizzle-orm/node-postgres')
    const { migrate } = await import('drizzle-orm/node-postgres/migrator')
    db = drizzle(new pg.Pool({ connectionString: databaseUrl }), { schema })
    await migrate(db, { migrationsFolder })
  }
  await seed(db)
  return db
}
```

```js
import { and, asc, eq, gt, inArray, lte, sql } from 'drizzle-orm'
import { grants, plans, sessionCharges } from '../db/schema.js'

const DAY_MS = 24 * 60 * 60 * 1000

/** Give a user a pack of the plan's minutes, valid for the plan's days from `now`. */
export async function grantPack(db, { userId, planId, source, now = new Date() }) {
  const [plan] = await db.select().from(plans).where(eq(plans.id, planId))
  if (!plan) throw new Error(`Unknown plan ${planId}`)
  const rows = await db
    .insert(grants)
    .values({
      userId,
      planId,
      minutesTotal: plan.minutes,
      startsAt: now,
      endsAt: new Date(now.getTime() + plan.validDays * DAY_MS),
      source
    })
    .onConflictDoNothing()
    .returning()
  return rows[0] ?? null
}

/** The once-per-account free pack (the unique index makes repeats a no-op). */
export function grantFreePack(db, userId, now = new Date()) {
  return grantPack(db, { userId, planId: 'free', source: 'free', now })
}

/** Usable packs (started, not expired, minutes left), soonest-expiring first. */
export async function activeGrants(db, userId, now = new Date()) {
  const rows = await db
    .select({ grant: grants, planName: plans.name })
    .from(grants)
    .innerJoin(plans, eq(grants.planId, plans.id))
    .where(and(eq(grants.userId, userId), lte(grants.startsAt, now), gt(grants.endsAt, now)))
    .orderBy(asc(grants.endsAt))
  if (!rows.length) return []

  const used = await db
    .select({
      grantId: sessionCharges.grantId,
      minutes: sql`coalesce(sum(${sessionCharges.minutes}), 0)`.mapWith(Number)
    })
    .from(sessionCharges)
    .where(inArray(sessionCharges.grantId, rows.map((r) => r.grant.id)))
    .groupBy(sessionCharges.grantId)
  const usedByGrant = new Map(used.map((u) => [u.grantId, u.minutes]))

  return rows
    .map(({ grant, planName }) => ({
      id: grant.id,
      planId: grant.planId,
      planName,
      minutesTotal: grant.minutesTotal,
      minutesLeft: Math.max(0, grant.minutesTotal - (usedByGrant.get(grant.id) ?? 0)),
      startsAt: grant.startsAt,
      endsAt: grant.endsAt,
      source: grant.source
    }))
    .filter((g) => g.minutesLeft > 0)
}

export async function minutesLeft(db, userId, now = new Date()) {
  return (await activeGrants(db, userId, now)).reduce((sum, g) => sum + g.minutesLeft, 0)
}
```

```js
import { appendFile } from 'node:fs/promises'

const DRIVERS = ['memory', 'console', 'outbox', 'resend']

/** Send transactional email. `console` and `outbox` are for development and tests only. */
export function createMailer({ driver = 'console', apiKey = '', from = 'Toonwide <no-reply@toonwide.app>', outboxFile = '', log = console } = {}) {
  if (!DRIVERS.includes(driver)) throw new Error(`Unknown mail driver ${driver}`)
  const sent = []

  async function send({ to, subject, text, html }) {
    const mail = { from, to, subject, text, html }
    if (driver === 'memory') {
      sent.push(mail)
    } else if (driver === 'console') {
      log.info(`[mail] to=${to} subject="${subject}"\n${text}`)
    } else if (driver === 'outbox') {
      await appendFile(outboxFile, `${JSON.stringify(mail)}\n`)
    } else {
      const res = await fetch('https://api.resend.com/emails', {
        method: 'POST',
        headers: { Authorization: `Bearer ${apiKey}`, 'Content-Type': 'application/json' },
        body: JSON.stringify({ from, to: [to], subject, text, html }),
        signal: AbortSignal.timeout(10000)
      })
      if (!res.ok) throw new Error(`Resend ${res.status}`)
    }
  }

  return { send, sent }
}
```

```js
/** Counts failures per key in a fixed window; `blocked` once `max` is reached. In memory, per process. */
export function createLimiter({ max = 5, windowMs = 15 * 60 * 1000, now = () => Date.now() } = {}) {
  const hits = new Map()

  function current(key) {
    const entry = hits.get(key)
    if (entry && now() - entry.start > windowMs) {
      hits.delete(key)
      return undefined
    }
    return entry
  }

  return {
    blocked: (key) => (current(key)?.count ?? 0) >= max,
    fail(key) {
      const entry = current(key)
      if (entry) entry.count++
      else hits.set(key, { start: now(), count: 1 })
    },
    reset: (key) => hits.delete(key)
  }
}
```

```js
/** Create a single-use link token; returns the raw token to put in the email. */
export async function createEmailToken(db, { userId, purpose, now = new Date() }) {
  const token = newToken()
  await db.insert(emailTokens).values({
    tokenHash: hashToken(token),
    userId,
    purpose,
    expiresAt: new Date(now.getTime() + EMAIL_TOKEN_TTL_MS[purpose])
  })
  return token
}

/** Mark the token used (atomically) and return its user id, or null if invalid, used, expired or wrong purpose. */
export async function consumeEmailToken(db, { token, purpose, now = new Date() }) {
  if (typeof token !== 'string' || !token) return null
  const [row] = await db
    .update(emailTokens)
    .set({ usedAt: now })
    .where(
      and(
        eq(emailTokens.tokenHash, hashToken(token)),
        eq(emailTokens.purpose, purpose),
        isNull(emailTokens.usedAt),
        gt(emailTokens.expiresAt, now)
      )
    )
    .returning({ userId: emailTokens.userId })
  return row?.userId ?? null
}
```

```js
    userAgent: userAgent ? String(userAgent).slice(0, 300) : null,
    expiresAt: new Date(now.getTime() + WEB_SESSION_MS)
  })
  return token
}

export async function findWebSessionUser(db, token, now = new Date()) {
  if (typeof token !== 'string' || !token) return null
  const [row] = await db
    .select({ user: users })
    .from(webSessions)
    .innerJoin(users, eq(webSessions.userId, users.id))
    .where(and(eq(webSessions.tokenHash, hashToken(token)), gt(webSessions.expiresAt, now), isNull(users.deletedAt)))
    .limit(1)
  return row?.user ?? null
}

export async function deleteWebSession(db, token) {
  if (typeof token === 'string' && token) await db.delete(webSessions).where(eq(webSessions.tokenHash, hashToken(token)))
}

/** Log a user out everywhere (e.g. after a password reset). */
export async function deleteUserWebSessions(db, userId) {
  await db.delete(webSessions).where(eq(webSessions.userId, userId))
}
```

```js
import { safeEqual } from '../util.js'
import { findWebSessionUser } from './webSessions.js'

export const SESSION_COOKIE = 'tw_session'
export const CSRF_COOKIE = 'tw_csrf'
const SAFE_METHODS = new Set(['GET', 'HEAD', 'OPTIONS'])

/** Sets req.user from the login cookie (or null). */
export function loadUser({ db, now }) {
  return async (req, _res, next) => {
    req.user = await findWebSessionUser(db, req.cookies?.[SESSION_COOKIE], now())
    next()
  }
}

export function requireUser(req, res, next) {
  if (!req.user) return res.status(401).json({ error: 'Please log in' })
  next()
}

/** Double-submit CSRF check: the header must echo the tw_csrf cookie. */
export function requireCsrf(req, res, next) {
  if (SAFE_METHODS.has(req.method)) return next()
  const cookie = req.cookies?.[CSRF_COOKIE]
  const header = req.get('x-csrf-token')
  if (!cookie || !header || !safeEqual(cookie, header)) {
    return res.status(403).json({ error: 'Your page is out of date. Refresh it and try again.' })
  }
  next()
}
```

```js
import express from 'express'
import { eq } from 'drizzle-orm'
import { z } from 'zod'
import { users } from '../db/schema.js'
import { grantFreePack } from '../billing/grants.js'
import { existingAccountMessage, resetEmailMessage, verifyEmailMessage } from '../mail/templates.js'
import { consumeEmailToken, createEmailToken } from './emailTokens.js'
import { CSRF_COOKIE, SESSION_COOKIE, loadUser, requireCsrf, requireUser } from './middleware.js'
import { hashPassword, passwordProblem, verifyPassword } from './password.js'
import { createLimiter } from './limiter.js'
import { newToken } from './tokens.js'
import { createWebSession, deleteUserWebSessions, deleteWebSession, WEB_SESSION_MS } from './webSessions.js'

const Email = z.string().trim().toLowerCase().pipe(z.email().max(254))
const Credentials = z.object({ email: Email, password: z.string().max(500) })
const TokenBody = z.object({ token: z.string().min(1).max(200) })
const ResetBody = z.object({ token: z.string().min(1).max(200), password: z.string().max(500) })

export function publicUser(user) {
  return { id: user.id, email: user.email, emailVerified: Boolean(user.emailVerifiedAt) }
}

/** Website login: sign up, verify email, log in/out, forgot/reset password. Mounted at /api/auth. */
export function authRouter({ db, mailer, config, now }) {
  const router = express.Router()
  const WINDOW_MS = 15 * 60 * 1000
  const emailFailures = createLimiter({ max: 5, windowMs: WINDOW_MS })
  // Higher per-IP ceiling: offices and phones on mobile data share one address.
  const ipFailures = createLimiter({ max: 50, windowMs: WINDOW_MS })
  // Sign-up and forgot-password emails, per IP: stops one visitor from mailing strangers in bulk.
  const mailRequests = createLimiter({ max: 30, windowMs: WINDOW_MS })
  let dummyHash
  const cookieBase = { secure: config.secureCookies, path: '/' }

  router.use(express.json({ limit: '16kb' }))
  router.use(requireCsrf)
  router.use(loadUser({ db, now }))

  const link = (path, token) => `${config.webUrl}${path}?token=${token}`

  async function sendVerification(user) {
    const token = await createEmailToken(db, { userId: user.id, purpose: 'verify', now: now() })
    await mailer.send({ to: user.email, ...verifyEmailMessage(link('/verify', token)) })
  }

  function tooManyMails(req, res) {
    if (mailRequests.blocked(`ip:${req.ip}`)) {
      res.status(429).json({ error: 'Too many requests. Try again in a few minutes.' })
      return true
    }
    mailRequests.fail(`ip:${req.ip}`)
    return false
  }

  router.get('/csrf', (req, res) => {
    const token = req.cookies?.[CSRF_COOKIE] || newToken()
    res.cookie(CSRF_COOKIE, token, { ...cookieBase, sameSite: 'strict', httpOnly: false, maxAge: WEB_SESSION_MS })
    res.json({ csrfToken: token })
  })

  router.post('/signup', async (req, res) => {
    const body = Credentials.safeParse(req.body)
    if (!body.success) return res.status(400).json({ error: 'Enter a valid email address' })
    const problem = passwordProblem(body.data.password)
    if (problem) return res.status(400).json({ error: problem })
    if (tooManyMails(req, res)) return

    const { email, password } = body.data
    const [existing] = await db.select().from(users).where(eq(users.email, email))
    if (existing?.emailVerifiedAt) {
      await mailer.send({ to: email, ...existingAccountMessage(`${config.webUrl}/login`) })
    } else if (existing) {
      await sendVerification(existing)
    } else {
      const [user] = await db
        .insert(users)
        .values({ email, passwordHash: await hashPassword(password) })
        .onConflictDoNothing()
        .returning()
      if (user) await sendVerification(user)
    }
    res.status(201).json({ ok: true })
  })

  router.post('/verify', async (req, res) => {
    const body = TokenBody.safeParse(req.body)
    const userId = body.success ? await consumeEmailToken(db, { token: body.data.token, purpose: 'verify', now: now() }) : null
    if (!userId) return res.status(400).json({ error: 'This link is invalid or has expired. Request a new one.' })
    await db.transaction(async (tx) => {
      const [user] = await tx.select().from(users).where(eq(users.id, userId))
      if (!user.emailVerifiedAt) await tx.update(users).set({ emailVerifiedAt: now() }).where(eq(users.id, userId))
      await grantFreePack(tx, userId, now())
    })
    res.json({ ok: true })
  })

  router.post('/resend-verification', requireUser, async (req, res) => {
    if (req.user.emailVerifiedAt) return res.status(400).json({ error: 'Your email is already verified' })
    if (tooManyMails(req, res)) return
    await sendVerification(req.user)
    res.json({ ok: true })
  })

  router.post('/login', async (req, res) => {
    const body = Credentials.safeParse(req.body)
    if (!body.success) return res.status(400).json({ error: 'Enter your email and password' })
    const { email, password } = body.data
    if (emailFailures.blocked(email) || ipFailures.blocked(req.ip)) {
      return res.status(429).json({ error: 'Too many attempts. Try again in 15 minutes or reset your password.' })
    }

    const [user] = await db.select().from(users).where(eq(users.email, email))
    // Verify against a dummy hash for unknown emails so response time doesn't reveal which emails exist.
    dummyHash ??= await hashPassword(newToken())
    const ok = (await verifyPassword(user?.passwordHash ?? dummyHash, password)) && user && !user.deletedAt
    if (!ok) {
      emailFailures.fail(email)
      ipFailures.fail(req.ip)
      return res.status(401).json({ error: 'Wrong email or password' })
    }

    emailFailures.reset(email)
    const token = await createWebSession(db, { userId: user.id, userAgent: req.get('user-agent'), now: now() })
    res.cookie(SESSION_COOKIE, token, { ...cookieBase, httpOnly: true, sameSite: 'lax', maxAge: WEB_SESSION_MS })
    res.json({ user: publicUser(user) })
  })

  router.post('/logout', async (req, res) => {
    await deleteWebSession(db, req.cookies?.[SESSION_COOKIE])
    res.clearCookie(SESSION_COOKIE, { ...cookieBase, httpOnly: true, sameSite: 'lax' })
    res.json({ ok: true })
  })

  router.get('/me', requireUser, (req, res) => res.json({ user: publicUser(req.user) }))

  router.post('/forgot', async (req, res) => {
    const email = Email.safeParse(req.body?.email)
    if (!email.success) return res.status(400).json({ error: 'Enter a valid email address' })
    if (tooManyMails(req, res)) return
    const [user] = await db.select().from(users).where(eq(users.email, email.data))
    if (user && !user.deletedAt) {
      const token = await createEmailToken(db, { userId: user.id, purpose: 'reset', now: now() })
      await mailer.send({ to: user.email, ...resetEmailMessage(link('/reset', token)) })
    }
    res.json({ ok: true })
  })

  router.post('/reset', async (req, res) => {
    const body = ResetBody.safeParse(req.body)
    if (!body.success) return res.status(400).json({ error: 'This link is invalid or has expired. Request a new one.' })
    const problem = passwordProblem(body.data.password)
    if (problem) return res.status(400).json({ error: problem })
    const userId = await consumeEmailToken(db, { token: body.data.token, purpose: 'reset', now: now() })
    if (!userId) return res.status(400).json({ error: 'This link is invalid or has expired. Request a new one.' })
    await db.update(users).set({ passwordHash: await hashPassword(body.data.password) }).where(eq(users.id, userId))
    await deleteUserWebSessions(db, userId)
    res.json({ ok: true })
  })

  return router
}
```

Note the reset check order: password policy is checked **before** consuming the token, so a rejected weak password
does not burn the link (the test relies on this).

```ts
  id: string
  email: string
  emailVerified: boolean
}
export interface Pack {
  id: string
  planName: string
  minutesTotal: number
  minutesLeft: number
  endsAt: string

  user: User
  minutesLeft: number
  packs: Pack[]

export class ApiError extends Error {
  status: number
  constructor(status: number, message: string) {
    super(message)
    this.status = status
  }
}

let csrf: string | null = null

async function csrfToken(): Promise<string> {
  if (!csrf) {
    const res = await fetch('/api/auth/csrf', { credentials: 'same-origin' })
    csrf = ((await res.json()) as { csrfToken: string }).csrfToken
  }
  return csrf
}

/** GET when `body` is undefined, otherwise POST with JSON and the CSRF header. */
export async function api<T>(path: string, body?: unknown): Promise<T> {
  const init: RequestInit = { credentials: 'same-origin' }
  if (body !== undefined) {
    init.method = 'POST'
    init.headers = { 'Content-Type': 'application/json', 'X-CSRF-Token': await csrfToken() }
    init.body = JSON.stringify(body)
  }
  const res = await fetch(`/api${path}`, init)
  const data = (await res.json().catch(() => ({}))) as { error?: string }
  if (!res.ok) throw new ApiError(res.status, data.error ?? `Something went wrong (${res.status})`)
  return data as T
}
```
